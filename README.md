## After Install: How To Use

### Start a Model Server

```cmd
cd %USERPROFILE%\quant-lab-llms
serve-model.bat qwen-coder
```

Server starts on `http://localhost:8001`. Test with:
```cmd
curl http://localhost:8001/v1/models
```

### Switch Between Models

Each model has its own port:
- `qwen-coder` → port 8001
- `deepseek-r1` → port 8002
- `phi35` → port 8003
- `llama31` → port 8004

Only run one at a time (they all need the GPU).

### Use From Claude Code

See `CLAUDE-CODE-INTEGRATION.md` — sets up an OpenAI-compatible API endpoint that Claude Code can hit as a fallback model.

### Use From Your Quant Code

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8001/v1",
    api_key="not-needed"
)

response = client.chat.completions.create(
    model="Qwen2.5-Coder-7B-Instruct-abliterated",
    messages=[
        {"role": "system", "content": "You write Pine Script v5 strategies for trading."},
        {"role": "user", "content": "Write a 9/30 EMA crossover strategy with volume filter"}
    ],
    temperature=0.3,
    max_tokens=2000
)
print(response.choices[0].message.content)
```

## If Something Fails

Common issues:
- **Out of VRAM during abliteration**: Run one model at a time. Restart the installer.
- **Python not in PATH after install**: Close and reopen terminal.
- **vLLM CUDA mismatch**: Reinstall with `pip install vllm --upgrade --force-reinstall`
- **Model not found on HuggingFace**: Some models are gated. May need `huggingface-cli login` first.

For anything else, message me in Telegram and I'll debug from VPS.
